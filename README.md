# DevLinks

Página simples de "link in bio" — um cartão de perfil com avatar e links rápidos para redes/sites.

## 🔗 Preview

Perfil com foto, @ de usuário e botões de link para:

- GitHub
- TeamZ

## 🛠️ Tecnologias

- CSS3

```
assets/

├── style.css
├── Avatar.png
└── bg-mobile.jpg
```

## ▶️ Como rodar

Basta abrir o arquivo `index.html` no navegador.
